Thermia ATEC Gateway – What It Does
===================================

For Thermia (formerly Danfoss) ATEC owners, this project replaces the Thermia Online gateway (DCM) with a small, low-cost ESP32 board that connects to the heat pump's room-stat terminal and is powered by the heat pump itself, with the existing room stat staying in place and working as normal. Once fitted, it brings the heat pump's data onto the home's own Wi-Fi and into Home Assistant, with no cloud account or subscription needed. Owners can see temperatures, heating-curve and hot-water settings, operating status and alarms in real time, keep a long-term history to spot problems or fine-tune efficiency, and adjust some settings from a phone or dashboard. Installation needs only a few low-voltage wires at terminal 121 and is fully reversible: the original gateway can be refitted at any time. It is currently a work-in-progress community project, tested on an ATEC running software 2.2.0 with DCM 2.0.15, so it comes with no guarantee and should be fitted by someone competent working inside the unit.

Home Assistant is free, open-source home-automation software that runs on a small always-on computer in the house, such as a Raspberry Pi or a dedicated Home Assistant Green box. It brings smart devices from many different brands together in one place, so the heat pump can sit alongside things like thermostats, solar panels, energy meters and lighting, and can even be used in automations, for example sending an alert if an alarm appears. At home, owners can open Home Assistant in any web browser on the home network or use the free Home Assistant app for iPhone and Android. For access away from home, the simplest option is Home Assistant Cloud (Nabu Casa), an optional paid subscription that gives secure remote access with no network setup and helps fund the Home Assistant project. Free alternatives, such as a VPN like Tailscale, are also available for those comfortable with a little more setup. Either way, the heat pump's data stays in the home, and remote access is simply a secure window into the owner's own system.
